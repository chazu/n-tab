NTab Options

Pinned tabs don't count. When a window exceeds n, the oldest tabs are moved to NTab.

When you open a duplicate page, move the existing tab to the far right, activate it, and close the new tab. Applies within the same window and container; pinned tabs are excluded.

Use full http:// or https:// URLs. * matches any number of characters (within the host or after it). Patterns select eligible pages; duplicates must still have the same full URL, including query and fragment. An empty list matches nothing.
