# NTab - Maintain N Tabs, Shunt the Oldest to NTab

NTab is a browser extension (for both Chrome and Firefox) which allows you to set _n_ - the maximum number of tabs allowed to be open at once in a single browser window. When a tab in opened in excess of this number, it is send to ntab - a OneTab style tab that tracks all unique web pages visited.

Pinned tabs are omitted from counting towards _n_.
